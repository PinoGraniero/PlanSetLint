# Changelog

## 0.2.0 — 2026-10-11

- Italian desktop interface with folder/CSV selectors, a background PDF check, issues and inventory tables.
- Configurable filename templates and reusable JSON profiles.
- Numeric or alphabetic revisions, custom paper dimensions, adjustable tolerance and optional recursive/multi-page checks.
- Local HTML, CSV and JSON exports with HTML escaping, spreadsheet-safe CSV and protection for input files.
- Synthetic demo with a clean package and a package containing five known anomalies.
- Mac/Windows source launchers and an Italian first-use guide.
- More robust CSV input validation, 19 validation tests and an additional real-Tk smoke check in CI.

## 0.1.0 — 2026-10-11

- Initial command-line prototype for PDF filenames, duplicate/missing drawings, revisions, page counts and A0–A4 sizes.
- CSV inventory, JSON output, MIT license and eight initial tests.
